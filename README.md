Using it
Open the HTML file in any browser, or upload it to any static host.
Click a project's "View case study" button to open its pop-up. Click any image in a pop-up or in the interests gallery to enlarge it.
Fonts (Outfit and Playfair Display) load from Google Fonts, so an internet connection is needed for them. The page falls back to Arial and Georgia without one.
